# -Projeto-RPGTarefa
Objetivo. Completar o sistema de cadastro de um jogo de RPG escrito em Python. Ele guarda jogadores, personagens, classes, itens e o inventário de cada personagem em um banco de dados. Você vai aprender a criar uma conexão com o banco, incluir registros, buscar por id e por nome e listar tudo usando comandos SQL.
